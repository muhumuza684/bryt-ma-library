# Repository Structure Notes

## Books

Each active book project lives under `books/` and should contain its governing
concept documentation before manuscript production begins.

Current locked concepts:
- Book 12 — Someone Better
- Book 13 — Lady Is a Man, Boy = Girl
- Book 14 — The Day He Could Not Bury Her
- Book 15 — When Time Comes

Completed/master-edition material:
- Rejections in Monaco
- God of Balimwezo omnibus

## Documentation layers

- `README.md` — public repository overview and book index.
- `PROGRESS.md` — project status tracker.
- `MASTER-GUIDE.md` — research and writing standards.
- `STYLE-GUIDE.md` — library-wide voice and style.
- `TODO.md` — deferred work and release-review checklist.
- `LOCKED-PROJECT-GUIDANCE.md` — guidance governing the newly locked
  concepts.

## Research

Fact-sensitive projects should keep research/source material separate from
manuscript prose. Book 14 now has a dedicated `RESEARCH-NOTES.md` file
because it is based on a documented real-world event.

## Packaged projects

ZIP packages may remain alongside their project documentation. When a
package is important to the repository, its README should explain what the
package contains and its role in the project.
