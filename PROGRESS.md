## How to Update This File
After finishing a chapter or making a structural decision on any book, update its row: bump the status, note the chapter count, and set "Last Touched" to the date. Keep this file as the single source of truth for "what's actually done" across the whole library. The individual book files describe *what* each book is; this file tracks *how far* each one has come.
